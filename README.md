# Subject Team — Official Website

> Modern, high-craft official landing page and ecosystem hub for **Subject Team** — engineering utility libraries, intelligent healthcare systems, vision pipelines, and resilient software architectures.

---

## ⚡ Tech Stack

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router, Static Export)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations & Physics:** [GSAP](https://gsap.com/) & [@gsap/react](https://gsap.com/resources/React/)
- **3D Graphics:** [Three.js](https://threejs.org/)
- **Smooth Scroll:** [Lenis](https://github.com/darkroomengineering/lenis)
- **Icons:** [Lucide React](https://lucide.dev/)
- **CI/CD:** [GitHub Actions](https://github.com/features/actions) → [GitHub Pages](https://pages.github.com/)

## 🛠️ Local Development

### 1. Prerequisites
- Node.js 18+ or 20+ (LTS recommended)
- npm, pnpm, or yarn

### 2. Installation
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the site.

### 4. Build Static Site
```bash
npm run build
```
The static HTML export will be generated in the `./out` directory.

## 🌐 Deployment to GitHub Pages

This repository is configured for automated CI/CD deployment to **GitHub Pages** using GitHub Actions (`.github/workflows/deploy.yml`).

### How to Activate GitHub Pages:
1. Push this repository to GitHub.
2. Go to your repository on GitHub: **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, select **GitHub Actions**.
4. Every push to the `main` branch will automatically trigger the build and deploy pipeline.
